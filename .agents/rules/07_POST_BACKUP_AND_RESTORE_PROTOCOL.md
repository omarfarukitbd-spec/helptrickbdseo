## 🏛️ ১. ব্যাকআপ নীতির মূল উদ্দেশ্য ও দর্শন
1. **জিরো ডেটা লস গ্যারান্টি (Zero Data Loss Guarantee):** কোনো পোস্ট সম্পাদনার পর যদি তথ্যে কোনো গরমিল হয় বা ইউজার আগের সংস্করণে ফিরে যেতে চান, তবে যেন কোনো তথ্য নষ্ট না হয়ে সাথে সাথে এক ক্লিকে হুবহু আগের অবস্থায় ফিরিয়ে আনা যায়।
2. **লেবেল সুরক্ষা (Label & Category Protection):** পোস্টটি পূর্বে কোন কোন লেবেলে (Labels) ছিল, তা কোনো অবস্থাতেই মুছে ফেলা বা হারিয়ে যেতে দেওয়া যাবে না। ব্যাকআপের মেটাডাটায় তা স্থায়ীভাবে লিপিবদ্ধ থাকবে।
3. **ইমেজ ও মিডিয়া ট্র্যাকিং (Image Manifest):** পোস্টে ব্যবহৃত মূল ছবি, ব্যানারের ইউআরএল, অল্টার টেক্সট (alt) ও টাইটেল হুবহু সংরক্ষিত থাকবে।

## 📁 ২. ব্যাকআপ ডিরেক্টরি কাঠামো (Standard Folder Structure)
প্রতিটি পোস্ট সম্পাদনার পূর্বে `backups/posts/<post-slug>/<timestamp>/` লোকেশনে নিচের ৪টি ফাইল স্বয়ংক্রিয়ভাবে তৈরি হতে হবে:

```
backups/
└── posts/
    └── honours-political-science-book-list/
        ├── 20260916_020442/
        │   ├── original_content.html    # পোস্টের ১০০% মূল অপরিবর্তিত এইচটিএমএল কোড
        │   ├── metadata.json            # পোস্ট আইডি, টাইটেল, লেবেল ও সময়কাল
        │   ├── images.json              # সমস্ত ইমেজ লিংক, alt ও title এর তালিকা
        │   └── README.md                # মানুষের পড়ার উপযোগী সার্বিক তথ্য বিবরণ
        └── latest/                      # সর্বশেষ ব্যাকআপের সরাসরি কপি (কুইক রিস্টোরের জন্য)
            ├── original_content.html
            ├── metadata.json
            └── images.json
```

## ⚙️ ৪. স্বয়ংক্রিয় ব্যাকআপ ইন্টারসেপ্টর (Automated Safety Gate)
ম্যানুয়াল ভুলের কোনো সুযোগ না রাখতে আপডেট স্ক্রিপ্টসমূহে (`tools/blogger_publisher/update_post.py` এবং সংশ্লিষ্ট পাবলিশিং পাইপলাইন) ব্যাকআপ ইন্টারসেপ্টর সরাসরি বিল্ট-ইন রাখা হয়েছে:

1. ব্লগারে কোনো পোস্টের `patch()` বা `update()` কল করার ঠিক আগে স্ক্রিপ্ট স্বয়ংক্রিয়ভাবে লাইভ পোস্টের সর্বশেষ অবস্থা ফেচ করবে।
2. `tools/backup_manager/post_backup_manager.py` কল করে ব্যাকআপ তৈরি করবে।
3. যদি ইনকামিং আপডেটে নতুন কোনো লেবেল উল্লেখ না থাকে, তবে পূর্বের লেবেল স্বয়ংক্রিয়ভাবে প্রিজার্ভ (সংরক্ষণ) করা হবে (কোনো লেবেল মোছা যাবে না)।

## 🔄 ৫. পোস্ট রিস্টোরেশন প্রটোকল (One-Click Instant Rollback)
যদি কোনো কারণে কোনো পোস্ট আগের অবস্থায় ফিরিয়ে নিতে হয়, তবে নিচের অটোমেটেড টুল ব্যবহার করতে হবে:

### ১. সংরক্ষিত সকল ব্যাকআপের তালিকা দেখতে:
```bash
python tools/backup_manager/restore_post.py --list
```

### ২. ড্রাই-রান (রিস্টোরের পূর্বরূপ দেখতে):
```bash
python tools/backup_manager/restore_post.py --slug <post-slug>
```

### ৩. সরাসরি ব্লগারে আগের পোস্ট ও লেবেল রিস্টোর করতে:
```bash
python tools/backup_manager/restore_post.py --slug <post-slug> --publish
```

## 🛡️ ৬. এজেন্ট চেকলিস্ট (Agent Pre-Edit Checklist)
যেকোনো এজেন্ট যেকোনো কম্পিউটারে পুরনো পোস্ট সম্পাদনার কাজ শুরু করার সময় অবশ্যই:
- [ ] পোস্টের লাইভ আইডি ও পারমালিঙ্ক সংগ্রহ করতে হবে।
- [ ] স্বয়ংক্রিয় ব্যাকআপ সচল রয়েছে কি না তা নিশ্চিত করতে হবে।
- [ ] মেটাডাটা ও মূল লেবেল যাচাই করতে হবে।
- [ ] কাজ শেষে গিট কমিটে ব্যাকআপ ফাইলগুলো গিটহাবে পুশ করে দিতে হবে।
