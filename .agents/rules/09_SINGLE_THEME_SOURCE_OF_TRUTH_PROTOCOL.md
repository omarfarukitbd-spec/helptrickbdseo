# 09_SINGLE_THEME_SOURCE_OF_TRUTH_PROTOCOL.md
# একক থিম সত্যতা ও দ্বি-ফোল্ডার থিম গভর্ন্যান্স নীতিমালা (Two-Folder Theme Governance Architecture)

এই রুলবুকটি হেল্পট্রিকবিডি প্রজেক্টের ওয়ার্ডপ্রেস থিম কোড সংরক্ষণ, সম্পাদন, দ্বি-ফোল্ডার আর্কিটেকচার বজায় রাখা এবং যে কোনো প্রকার কোড ডুপ্লিকেশন সম্পূর্ণ নির্মূল করার জন্য চূড়ান্ত আইন হিসেবে বিবেচিত হবে।

---

## 🏛️ ১. দ্বি-ফোল্ডার থিম আর্কিটেকচার (The 2-Folder Mandatory Architecture)
প্রজেক্টের থিম ফাইল ব্যবস্থাপনায় স্বচ্ছতা ও সর্বোচ্চ নিরাপত্তা নিশ্চিত করতে রুটে ২টি সুনির্দিষ্ট ফোল্ডার বজায় রাখা প্রতিটি এজেন্টের জন্য বাধ্যতামূলক:

```
E:\Helptrickbd\
├── Theme Backups/              # [ফোল্ডার ০১] প্রতিটি কাজের শুরুর পূর্বে বাধ্যতামূলক প্রি-এডিট ব্যাকআপ ভল্ট
│   ├── wp_theme_.../          # টাইমস্ট্যাম্পড ব্যাকআপ (আনপ্যাকড কোড + সিপ্যানেল/ওয়ার্ডপ্রেস রেডি জিপ)
│   ├── latest/                # সর্বশেষ সচল ব্যাকআপ সংস্করণ
│   └── README.md              # ব্যাকআপ তালিকা ও রিস্টোর গাইড
│
└── Updated Theme/              # [ফোল্ডার ০২] সর্বশেষ হালনাগাদকৃত প্রোডাকশন থিম ভল্ট
    ├── helptrickbd-theme/     # সর্বশেষ আপডেট হওয়া সম্পূর্ণ সোর্স কোড (PHP, CSS, JS)
    ├── helptrickbd-theme.zip  # লাইভ ওয়ার্ডপ্রেসে ১-ক্লিকে আপলোড করার প্রস্তুত জিপ
    ├── helptrickbd-theme-vX.X.X.zip # নির্দিষ্ট সংস্করণ জিপ
    └── README.md              # বর্তমান সংস্করণ ও লাইভ আপডেট গাইড
```

## 🛑 ২. থিম এডিট শুরুর পূর্বে বাধ্যতামূলক প্রি-এডিট ব্যাকআপ (MANDATORY STOP-GATE)

> [!CAUTION]
> **কঠোর অলঙ্ঘনীয় নিয়ম (NON-NEGOTIABLE RULE)**:
> থিমের কোনো পিএইচপি (PHP), সিএসএস (CSS), জাভাস্ক্রিপ্ট (JS) বা কনফিগারেশন ফাইলে যে কোনো ধরনের পরিবর্তন, নতুন ফিচার যোগ, রিফ্যাক্টরিং বা বাগ ফিক্স শুরু করার পূর্বে **বাধ্যতামূলকভাবে `Theme Backups/` ফোল্ডারে একটি টাইমস্ট্যাম্পড প্রি-এডিট ব্যাকআপ সংরক্ষণ করতে হবে**। কোনো অবস্থাতেই ব্যাকআপ না নিয়ে থিমের কোডে হাত দেওয়া সম্পূর্ণ নিষিদ্ধ।

### ব্যাকআপ কমান্ড (Mandatory Pre-Flight Execution):
যেকোনো থিম কোডে হাত দেওয়ার পূর্বে এজেন্টদের অবশ্যই এই কমান্ড রান করে ব্যাকআপ নিশ্চিত করতে হবে:
```bash
python tools/backup_manager/theme_backup_manager.py backup --reason "<আপনার পরিবর্তনের উদ্দেশ্য>"
```

## 🚀 ৩. কাজ শেষের পর বাধ্যতামূলক প্যাকেজিং ও আপডেট (MANDATORY POST-EDIT PACKAGING)

> [!IMPORTANT]
> **আপডেট থিম ফোল্ডার সিঙ্ক বাধ্যবাধকতা**:
> থিমে কোড পরিবর্তন ও যাচাইকরণ সম্পন্ন হওয়া মাত্রই এজেন্টকে অবশ্যই **`Updated Theme/`** ফোল্ডারে সর্বশেষ কোড এবং ইনস্টলেবল `helptrickbd-theme.zip` প্যাকেজ আপডেট করতে হবে। কোনো কাজ শেষ করার পর যদি `Updated Theme/` আপডেট না থাকে, তবে সেই কাজ অসম্পূর্ণ ও রুল লঙ্ঘন হিসেবে গণ্য হবে।

### প্যাকেজিং ও সিঙ্ক কমান্ড:
```bash
python tools/backup_manager/theme_backup_manager.py package
```
এই কমান্ডটি স্বয়ংক্রিয়ভাবে:
1. সর্বশেষ থিম ফাইলসমূহ `Updated Theme/helptrickbd-theme/` এ সিঙ্ক করে।
2. নতুন সংস্করণ অনুযায়ী ক্লিন UNIX POSIX পারমিশনযুক্ত `helptrickbd-theme.zip` তৈরি করে।
3. `Updated Theme/README.md` ফাইলে বর্তমান ভার্সন ও তারিখ স্বয়ংক্রিয়ভাবে হালনাগাদ করে।

## ⚡ ৪. ইনস্ট্যান্ট ১-ক্লিক রোলব্যাক গ্যারান্টি (Instant 1-Click Rollback)
কোনো কোড পরিবর্তনের পর যদি সাইটে সিএসএস ভাঙা, পিএইচপি সিনট্যাক্স এরর, হোয়াইট স্ক্রিন অব ডেথ (WSOD) বা কোনো সমস্যা দেখা দেয়:
1. অনুমানের ওপর ভিত্তি করে নতুন এডিট চাপানো সম্পূর্ণ নিষিদ্ধ।
2. তাৎক্ষণিকভাবে রোলব্যাক টুল রান করে পূর্ববর্তী সচল ব্যাকআপ ফিরিয়ে আনতে হবে:
   ```bash
   python tools/backup_manager/theme_backup_manager.py restore
   ```
3. লাইভ সার্ভারে জরুরি প্রয়োজনে `Theme Backups/latest/helptrickbd-theme-latest.zip` ফাইলটি আপলোড করে মুহূর্তেই সাইট পূর্বাবস্থায় সচল করতে হবে।

## 📂 ৫. মডুলার স্ট্রাকচার ও একক সত্য ডিরেক্টরি (Modular Structure & In-Place Editing)
- থিমের যাবতীয় কাজ সরাসরি নির্ধারিত মডুলার ফাইলে করতে হবে:
  * গ্লোবাল লেআউট ও কালার টোকেন: `assets/css/main.css`
  * পোস্ট আর্টিকেল ও টাইপোগ্রাফি: `assets/css/single.css`
  * ডার্ক মোড স্যানিটাইজার মডিউল: `inc/content-cleaner.php`
  * ৩০১ পার্মানেন্ট রিডাইরেক্ট ইঞ্জিন: `inc/redirect-engine.php`
  * ইন্টারনাল লিঙ্ক রি-রাইটার: `inc/link-rewriter.php`
  * আইকন সিস্টেম (Pure SVG): `inc/material-icons.php`
- **আলাদা স্নিপেট তৈরি কঠোরভাবে নিষিদ্ধ:** কোনো এজেন্ট আলাদা কোনো খণ্ডিত সিএসএস বা স্ক্রিপ্ট ফাইল বাইরে তৈরি করতে পারবে না।

## 🎨 ৬. শূন্য ডুপ্লিকেশন, জিরো-ইমোজি ও ডার্ক মোড স্ট্যান্ডার্ড (WCAG 2.1 AA)
- **জিরো ইমোজি:** থিমের কোনো পিএইচপি, সিএসএস, জেএস বা জেনারেটেড এইচটিএমএল-এ কোনো ইউনিকোড ইমোজি থাকা কঠোরভাবে নিষিদ্ধ (Rule 12)। শুধুমাত্র `ht_m3_icon()` এর মাধ্যমে Google Material 3 ভেক্টর এসভিজি (Pure SVG) আইকন ব্যবহার করতে হবে।
- **ডার্ক মোড কনট্রাস্ট:** ডার্ক মোডে টেক্সট কখনো ব্যাকগ্রাউন্ডের সাথে মিশতে পারবে না (কনট্রাস্ট রেশিও ন্যূনতম ৭:১)। কলআউট বক্সগুলো ডার্ক মোডে স্লিম ডার্ক স্লেট (`#1e293b`) এবং টেক্সট উজ্জ্বল হাই-কনট্রাস্ট (`#f1f5f9`) হতে হবে।
