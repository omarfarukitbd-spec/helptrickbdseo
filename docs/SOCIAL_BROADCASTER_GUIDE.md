# হেল্পট্রিকবিডি সোশ্যাল ব্রডকাস্টার সেটআপ ও ব্যবহার নির্দেশিকা

এই নির্দেশিকা অনুসরণ করে টেলিগ্রাম চ্যানেল বট, ফেসবুক পেজ মেটা গ্রাফ এপিআই এবং হোয়াটসঅ্যাপ চ্যানেলের ১-ক্লিক ব্রডকাস্টার কনফিগার ও ব্যবহার করা যাবে।

---

## ১. সিস্টেম পরিচিতি ও বৈশিষ্ট্য

- **প্রিভিউ ফার্স্ট (Preview First):** কোনো সোশ্যাল প্ল্যাটফর্মে পোস্ট পাঠানোর পূর্বে টার্মিনালে প্রতিটি প্ল্যাটফর্মের জন্য তৈরি হওয়া পোস্টের সম্পূর্ণ প্রিভিউ প্রদর্শিত হবে এবং ব্যবহারকারীর চূড়ান্ত সম্মতি (y/n) চাওয়া হবে।
- **মানবিক ও আর্কিটাইপ-ভিত্তিক কপি:** একঘেয়ে রোবটিক টেক্সটের বদলে পোস্টের ক্যাটাগরি (চাকরির সার্কুলার, স্টাডি গাইড, টেক টিউটোরিয়াল, সাধারণ প্রবন্ধ) অনুযায়ী স্বতন্ত্র হুক, মূল পয়েন্ট ও মানানসই কল-টু-অ্যাকশন (CTA) তৈরি হয়।
- **জিরো ইমোজি পলিসি (Rule 12):** কোনো বিভ্রান্তিকর বা অনাকাঙ্ক্ষিত ইমোজি ছাড়াই মার্জিত ও প্রফেশনাল টাইপোগ্রাফি নিশ্চিত করা হয়েছে।
- **নিরাপদ ক্রেডেনশিয়াল ব্যবস্থাপনা:** এপিআই কি ও টোকেনসমূহ `tools/social_broadcaster/social_credentials.json` ফাইলে সংরক্ষিত থাকে যা `.gitignore` দ্বারা গিটহাবে পুশ হওয়া থেকে সম্পূর্ণ সুরক্ষিত।

## ২. টেলিগ্রাম চ্যানেল ও বট সেটআপ গাইড (১০০% ফ্রি ও ২ মিনিট সময়)

### ধাপ ০১: টেলিগ্রাম বট তৈরি
১. টেলিগ্রাম অ্যাপের সার্চবারে লিখুন `@BotFather` এবং ভেরিফায়েড চ্যাটে প্রবেশ করুন।
২. মেসেজ বক্সে লিখুন: `/newbot` এবং সেন্ড করুন।
৩. বটের একটি নাম নির্ধারণ করুন (যেমন: `HelpTrickBD Official Bot`)।
৪. বটের একটি ইউনিক ইউজারনেম দিন যার শেষে `bot` থাকতে হবে (যেমন: `helptrickbd_bot` বা `htbd_post_bot`)।
৫. BotFather আপনাকে একটি **HTTP API Token** প্রদান করবে (উদাহরণ: `7890123456:AAFlk...`)। এই টোকেনটি কপি করে রাখুন।

### ধাপ ০২: চ্যানেলে বটকে অ্যাডমিন হিসেবে যোগ করা
১. আপনার হেল্পট্রিকবিডি অফিসিয়াল টেলিগ্রাম চ্যানেলে প্রবেশ করুন।
২. Channel Settings -> Administrators -> **Add Administrator** এ ক্লিক করুন।
৩. আপনার তৈরি করা বটের ইউজারনেম লিখে সার্চ করে অ্যাডমিন হিসেবে যুক্ত করুন এবং পোস্ট করার অনুমতি (Post Messages) চালু রাখুন।

### ধাপ ০৩: কনফিগারেশন ফাইলে টোকেন বসানো
`tools/social_broadcaster/social_credentials.json` ফাইলটি ওপেন করে টেলিগ্রাম সেকশনে টোকেন ও চ্যানেল ইউজারনেম দিন:
```json
"telegram": {
  "bot_token": "আপনার_টেলিগ্রাম_বট_টোকেন_এখানে_বসাবেন",
  "channel_id": "@helptrickbd_official",
  "enabled": true
}
```

## ৩. ফেসবুক পেজ মেটা গ্রাফ এপিআই সেটআপ গাইড

### ধাপ ০১: মেটা ডেভেলপার অ্যাকাউন্ট ও অ্যাপ তৈরি
১. ব্রাউজারে `https://developers.facebook.com/` এ গিয়ে আপনার ফেসবুক অ্যাকাউন্ট দিয়ে লগইন করুন।
২. উপরের ডানপাশের **My Apps** -> **Create App** এ ক্লিক করুন।
৩. ইউজকেস হিসেবে **Other** অথবা **Business** নির্বাচন করুন।
৪. অ্যাপের একটি নাম দিন (যেমন: `HelpTrickBD Auto Poster`) এবং অ্যাপ তৈরি সম্পন্ন করুন।

### ধাপ ০২: গ্রাফ এপিআই এক্সপ্লোরারে পেজ এক্সেস টোকেন জেনারেট
১. ব্রাউজারে `https://developers.facebook.com/tools/explorer/` ওপেন করুন।
২. ডানপাশের **Meta App** ড্রপডাউনে আপনার তৈরি করা অ্যাপটি নির্বাচন করুন।
৩. **User or Page** ড্রপডাউনে ক্লিক করে আপনার হেল্পট্রিকবিডি ফেসবুক পেজটি সিলেক্ট করুন।
৪. **Permissions** অপশনে গিয়ে নিচের পারমিশনগুলো যোগ করুন:
   - `pages_show_list`
   - `pages_read_engagement`
   - `pages_manage_posts`
৫. **Generate Access Token** বাটনে ক্লিক করে ফেসবুক থেকে অনুমতি দিন।

### ধাপ ০৩: পার্মানেন্ট (Never-Expiring) পেজ টোকেন নেওয়া
১. এক্সেস টোকেন বক্সের পাশে ছোট তথ্য আইকনে (Info) ক্লিক করে **Open in Access Token Tool** এ ক্লিক করুন।
২. **Extend Access Token** এ ক্লিক করলে আপনি একটি দীর্ঘমেয়াদী টোকেন পাবেন যা কখনো মেয়াদোত্তীর্ণ হবে না।
৩. সেই টোকেনটি এবং আপনার পেজের আইডি কপি করুন।

### ধাপ ০৪: কনফিগারেশন ফাইলে বসানো
`tools/social_broadcaster/social_credentials.json` ফাইলের ফেসবুক সেকশনে বসান:
```json
"facebook": {
  "page_id": "আপনার_ফেসবুক_পেজ_আইডি",
  "page_access_token": "আপনার_ফেসবুক_পেজ_এক্সেস_টোকেন",
  "enabled": true
}
```

## ৪. হোয়াটসঅ্যাপ চ্যানেল নিরাপদ ১-ক্লিক শেয়ার

হোয়াটসঅ্যাপে আনঅফিসিয়াল থার্ড-পার্টি আনঅথরাইজড এপিআই ব্যবহারের ফলে ফোন নাম্বার বা চ্যানেল ব্যান হওয়ার মারাত্মক ঝুঁকি থাকে।
তাই হেল্পট্রিকবিডি সিস্টেমে শতভাগ ঝুঁকিহীন **১-ক্লিক ওয়েব হেল্পার** যুক্ত করা হয়েছে:
- পোস্ট পাবলিশের পর স্বয়ংক্রিয়ভাবে প্ল্যাটফর্মের জন্য প্রস্তুত করা টেক্সট কম্পিউটারের ক্লিপবোর্ডে কপি হয়ে যায়।
- একইসাথে ব্রাউজারে অফিসিয়াল হোয়াটসঅ্যাপ চ্যানেল পেজ ওপেন হয়।
- ব্যবহারকারী শুধুমাত্র মেসেজ বক্সে `Ctrl + V` চেপে পেস্ট করে পোস্ট সম্পন্ন করতে পারেন।

## ৫. কমান্ড ও ব্যবহার প্রণালী

### ক. কনফিগারেশন ও সংযোগ পরীক্ষা
```bash
python tools/social_broadcaster/broadcaster.py --check-config
```

### খ. কোনো চ্যানেলে ডেটা না পাঠিয়ে শুধু প্রিভিউ দেখা (Dry-Run)
```bash
python tools/social_broadcaster/broadcaster.py --dry-run --post-file "path/to/post.html" --title "পোস্টের শিরোনাম" --post-url "https://www.helptrickbd.com/post-url.html" --labels "চাকরি, বিসিএস"
```

### গ. লাইভ ইউআরএল দিয়ে সোশ্যাল পোস্ট ব্রডকাস্ট
```bash
python tools/social_broadcaster/broadcaster.py --post-url "https://www.helptrickbd.com/2026/09/sample-post.html"
```

### ঘ. মাস্টার পাবলিশিং পাইপলাইনের সাথে স্বয়ংক্রিয়ভাবে চালানো
```bash
python tools/pipeline/master_publisher_pipeline.py --html "path/to/post.html" --publish --post-id "123456789" --url "https://www.helptrickbd.com/post.html" --broadcast
```
