# Output Posts Directory

All generated world-class SEO articles are saved here.

For each generated post, you will find:
1. `<slug>.html`: The complete, theme-styled article ready to paste into the Blogger HTML editor.
2. `<slug>_metadata.json`: The companion metadata containing:
   - Post Title (Optimized for Google SERP CTR)
   - Labels / Category
   - Scheduled Release Time (Strictly 7:00 PM - 8:30 PM BST)
   - Search Description (Under 155 characters)
   - Custom Permalink Slug
