# 📖 Help Trick BD (WordPress Migration & Full Content Import Guide)

ব্লগার (`arafatitbd.blogspot.com`) থেকে ওয়ার্ডপ্রেস (`www.helptrickbd.com`)-এ **১০০% সম্পূর্ণ পোস্ট (Full Post Body)** মাইগ্রেশনের চূড়ান্ত গাইড।

> ⚠️ **পূর্ববর্তী সমস্যার সমাধান (Fixed Jump-Break Issue):**
> পূর্বে ব্লগার ফিড (`/feeds/posts/default`) থেকে ডেটা নেওয়ার কারণে যেসব পোস্টে জাম্প-ব্রেক (`<a name='more'></a>`) ছিল, ব্লগার স্বয়ংক্রিয়ভাবে সেগুলোর শুধু ভূমিকা অংশ পাঠিয়েছিল এবং মূল লেখা কেটে গিয়েছিল। 
> এই নতুন সংস্করণে আমরা সরাসরি লাইভ ব্লগ পোস্ট পেজগুলো স্ক্র্যাপ করে সম্পূর্ণ পোস্টের পূর্ণাঙ্গ বডি (বড় বড় টেবিল, প্রশ্নব্যাংক, গাইডলাইন, সূত্র ও বিশ্লেষণ সহ) উদ্ধার করেছি এবং মোট শব্দের পরিমাণ **৬,৩২,৯২৮ শব্দে** উন্নীত করেছি! জাম্প-ব্রেকগুলোকে ওয়ার্ডপ্রেসের আদর্শ `<!--more-->` ট্যাগে রূপান্তর করা হয়েছে।

## 🧹 গুরুত্বপূর্ণ ধাপ: পূর্বে ইমপোর্ট করা অসম্পূর্ণ পোস্টগুলো ক্লিয়ার করা

যেহেতু পূর্বে জাম্প-ব্রেকের কারণে কিছু পোস্টের কেবল প্রথম কয়েক লাইন ইমপোর্ট হয়েছিল, তাই ওয়ার্ডপ্রেসে ডুপ্লিকেট রোধ করতে এবং পূর্ণাঙ্গ পোস্ট সফলভাবে প্রতিস্থাপন করতে:

1. ওয়ার্ডপ্রেস অ্যাডমিনে যান: **Posts > All Posts**।
2. যদি আগে কোনো পোস্ট ইমপোর্ট করে থাকেন, তবে সবগুলো সিলেক্ট করে **Bulk Actions > Move to Trash** দিন।
3. এরপর **Trash** ট্যাবে গিয়ে **Empty Trash** বাটনে ক্লিক করুন। 
*(যদি ডাটাবেস সম্পূর্ণ ফাঁকা বা নতুন সাইট হয়, তবে এই ধাপের প্রয়োজন নেই।)*

## 🚀 ধাপ ১: পারমালিংক নিশ্চিত করা (Permalink Setup)

1. ওয়ার্ডপ্রেস অ্যাডমিনে যান: **Settings > Permalinks**।
2. **Post name** (`/%postname%/`) সিলেক্ট করুন।
3. **Save Changes**-এ ক্লিক করুন।

## 📥 ধাপ ২: ৩টি ফাইল ধাপে ধাপে ইমপোর্ট করার নিয়ম

1. ওয়ার্ডপ্রেস ড্যাশবোর্ডে যান: **Tools > Import**।
2. **WordPress** অপশনের নিচে **Run Importer**-এ ক্লিক করুন (ইনস্টল না থাকলে প্রথমে *Install Now* দিন)।

### 🔹 ১ম ফাইল আপলোড:
- **Choose File**-এ ক্লিক করে সিলেক্ট করুন:
  ```
  d:\android\Project\Helptrickbd Wp\helptrickbd_part1_posts_01_to_45.xml
  ```
- **Upload file and import**-এ ক্লিক করুন।
- **Assign Authors:** আপনার অ্যাডমিন ইউজার (যেমন: `ayesha`) সিলেক্ট করুন।
- **Download and import file attachments:** আনচেক (খালি) রাখতে পারেন, কারণ সব ছবি দ্রুতগতির গ্লোবাল ক্লাউড সিডিএন (`cdn.jsdelivr.net` / WebP)-এ হোস্ট করা রয়েছে। এতে আপনার হোস্টিং স্টোরেজ পুরোপুরি ফ্রি থাকবে।
- **Submit** বাটনে ক্লিক করুন। ১ম ৪৫টি ফুল পোস্ট ইমপোর্ট হয়ে যাবে।

### 🔹 ২য় ফাইল আপলোড:
- পুনরায় **Tools > Import > WordPress (Run Importer)**-এ যান।


### 🔹 ৩য় ফাইল আপলোড:

- সিলেক্ট করুন:

  ```
  d:\android\Project\Helptrickbd Wp\helptrickbd_part3_posts_91_to_134.xml
  ```

- অথর সিলেক্ট করে **Submit** করুন। বাকি ৪৪টি ফুল পোস্ট চলে আসবে।

## 📄 ধাপ ৩: ব্লগের স্ট্যাটিক পেজসমূহ ইমপোর্ট করার নিয়ম (Pages Import)

ব্লগারের সকল স্ট্যাটিক পেজ (যেমন: সিজিপিএ ক্যালকুলেটর, কভার পেজ, About Us, Contact Us, Privacy Policy ইত্যাদি) ওয়ার্ডপ্রেসের **Pages** সেকশনে আনার জন্য প্রস্তুতকৃত ফাইল:
```
d:\android\Project\Helptrickbd Wp\helptrickbd_pages_import.xml
```

### আপলোড করার নিয়ম:
1. পুনরায় ওয়ার্ডপ্রেস ড্যাশবোর্ডে যান: **Tools > Import > WordPress (Run Importer)**।
2. **Choose File**-এ ক্লিক করে সিলেক্ট করুন:
   ```
   d:\android\Project\Helptrickbd Wp\helptrickbd_pages_import.xml
   ```
3. **Upload file and import** দিন এবং অথর সিলেক্ট করে **Submit** করুন।
4. সাথে সাথে নিচের **৯টি পেজ** আপনার ওয়ার্ডপ্রেসের **Pages > All Pages**-এ চলে আসবে:
   * **জাতীয় বিশ্ববিদ্যালয় সিজিপিএ ক্যালকুলেটর** (`/nu-cgpa-calculator/`) — সম্পূর্ণ ইন্টারঅ্যাক্টিভ জাভাস্ক্রিপ্ট টুল সহ।
   * **অ্যাসাইনমেন্ট ও টার্ম পেপার কভার পেজ মেকার** (`/cover-page/`) — কভার পেজ জেনারেটর টুল সহ।
   * **আমাদের সম্পর্কে (About Us)** (`/about-us/`)
   * **যোগাযোগ (Contact Us)** (`/contact-us/`)
   * **গোপনীয়তা নীতি (Privacy Policy)** (`/privacy-policy/`)
   * **শর্তাবলী (Terms & Conditions)** (`/terms-conditions/`)
   * **দাবিত্যাগ (Disclaimer)** (`/disclaimer/`)
   * **কুকি নীতিমালা (Cookie Policy)** (`/cookie-policy/`)
   * **সাইটম্যাপ (HTML Sitemap)** (`/sitemap/`)

## 🎯 Rank Math SEO বৈশিষ্ট্যসমূহ যা প্রতিটি পোস্টে যুক্ত হয়েছে

2. **মেটা টাইটেল ও ডেসক্রিপশন:** গুগল সার্চ ইঞ্জিনে আকর্ষণীয় স্নsnippet প্রদর্শনের জন্য প্রমিত দৈর্ঘ্য বজায় রাখা হয়েছে।
3. **Robots Index:** গুগল ও অন্যান্য সার্চ ইঞ্জিনে ইনডেক্স হওয়ার জন্য `index` কনফিগার করা আছে।

5. **অভ্যন্তরীণ লিঙ্কিং (Internal Links):** আগের সাইটের (`arafatitbd.blogspot.com`) সকল অভ্যন্তরীণ লিঙ্ক পরিবর্তন করে নতুন সাইটের ঠিকানায় (`https://www.helptrickbd.com/slug/`) কনভার্ট করা হয়েছে।
